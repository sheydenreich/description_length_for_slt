Learner coefficients (regret slope per ln n of the MAP code, batching-corrected, n = 16..1024, 3 seeds) for
every recorded configuration of the single-map learner; `bitsev-h-a3 <run> --n-min 64`. The regret is the
prequential loss minus the loss of the final fit on the same targets. For the MAP learner this is the
learner's coefficient kappa in the plan's sense (T4), not the Bayes lambda; the two coincide only for a
Bayes predictive in a regular model.

Reading. (1) The manufactured alignment's coefficient is 20x the valid alignment's on GPT-2 (988 vs 49)
and 30x on InterpBench (255 vs 8): the expressive map on the untrained network keeps paying for every
block, the valid subspace stops paying once its span is found. In the plan's decomposition of the gain,
G(n) = n*delta_loss + delta_lambda*ln n + ..., the valid-vs-manufactured comparison is carried by the
coefficient term as well as by the loss term. (2) The same coupling family on the trained network has
a coefficient of 225 (GPT-2) / 474 (InterpBench): the family's coefficient depends on the network it is
attached to, i.e. on the data distribution, as a learning coefficient should. (3) Both valid subspaces
were measured below their parameter count (12288 and 1040 frame parameters at n <= 1024); the 8192-
and 32768-target runs (InterpBench done / queued, GPT-2 jobs bitsev-ioi-map-n8192 and -n32768 submitted
2026-10-20) measure the asymptotic regime.
